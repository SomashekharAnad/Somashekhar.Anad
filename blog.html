OPC UA vs Modbus at the edge

Modbus is still everywhere in brownfield plants. It is simple, deterministic and supported by nearly every device, but it has no data model and no built-in security.

OPC UA adds a rich information model, certificate-based security and discovery. In Edgenius validation, a common pattern is to keep Modbus at device level and normalize data into OPC UA or PubSub before it leaves the site.

My checklist: confirm register maps early, test byte order explicitly, validate certificate trust lists on both client and server, and include reconnect scenarios in every test plan.

Lessons from five Symphony Plus upgrades

Upgrading a power-station DCS depends on preparation more than speed.

What worked: freezing the tag database before migration, scripting faceplate checks, and validating redundant server peering before cut-over, not after.

What I repeat on every project: a firmware compatibility matrix for HC800/CP800/IET800, and a rollback plan rehearsed with the site team.

How we test Connect on Demand

Connect on Demand gives engineers remote access only when it is needed. Testing it means proving both that access works and that it closes properly.

Our test cases cover session start and expiry, role permissions, network interruptions and audit logging.

Every defect report includes the LMS version, topology diagram, logs and exact reproduction steps, which considerably shortens R&D turnaround.
